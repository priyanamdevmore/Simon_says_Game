# Simon_says_Game
This Simon Says Game

# How to play Simon says game.
1. Start the game by pressing the Start button (or any key, depending on the version).
2. The game will flash a colored button (for example, Green).
3. Click the same color that flashed.
4. In the next level, the game adds one more color to the sequence.

   Example: Green → Red
5. Repeat the entire sequence in the correct order.
6. After each successful level, the sequence becomes longer and more difficult.
7. If you click a wrong color:

    The game ends.
    A "Game Over" message or sound is played.
8. Restart the game and try to beat your previous score.

# Example

 Level 1: Green → Click Green
 Level 2: Green, Red → Click Green, Red
 Level 3: Green, Red, Yellow → Click Green, Red, Yellow
Continue until you make a mistake.
